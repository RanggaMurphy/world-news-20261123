# The World Today — Monday, 23 November 2026

make.fun news-image entry: one image summing up 23 November's world news.

`entry.png` (1024x1024) is the entry itself, rendered by `render.py` from
`sources.json` and the photos in `thumbs/`. Every headline was confirmed by
at least two outlets; see `sources.json` for the confirming outlets.

`main.py` is the entrypoint the grader runs (stdlib only): it copies
`entry.png` into `MAKEFUN_OUTPUT_DIR`.
